> 阶段：06-社区与资讯  

## 定位说明

高质量技术博客、综合社区和 Obsidian 社区的入口汇总。长期跟踪、定期访问的内容来源，价值在于持续接收业界高质量输出。

## 一、个人技术博客

- **中文**：云风（codingnow.com）、阮一峰（ruanyifeng.com）、循迹研究室（imzlp.com，侧重 UE/游戏工程）、luzexi.com（游戏客户端）、yuque/et-xd（ET 框架）、桫椤 / fangyukuan（博客园）
- **海外 / 英文**：Doug Lea（并发理论）、Aaron Bos（C#）、code-corner.dev、Holger's Code、vishalchovatiya.com（设计模式）、Riot Games Technology（游戏工程实践）
- **Unity 日文博客**：テラシュールブログ（Unity 日文社区质量较高，适合查阅冷门 API 技巧）

## 二、综合 / 聚合社区

- **Hacker News**：技术热点聚合，讨论质量高，适合了解英文社区动态
- **Reddit**（r/csharp 等）：垂直技术社区，问题解答实用
- **DEV Community**（dev.to）：轻量技术博文发布平台
- **稀土掘金**（juejin.cn）：国内中文技术社区，前端 / 移动端内容质量较高
- **Linux DO**：理想型社区，话题质量有保障
- **Road 2 Coding**（r2coding.com）：编程路线汇总站
- **HelloGitHub**：优质开源项目定期推荐

## 三、Bilibili 资讯

- B 站排行榜 / 动态首页：泛技术视频入口，ET 框架、UGUI、游戏同步等专项内容质量较高
- 关注 UP：egametang（ET 作者）、小白debug、阿赵 3D（CSDN）

## 四、Obsidian / 笔记社区

- Obsidian 中文论坛（forum-zh.obsidian.md）：插件讨论和工作流分享
- 月度热门版块适合定期回顾新工具和工作流玩法

## 五、零散文章入口

> NGA 论坛 / ngabbs 等需登录后才能访问，已移入私有元数据。

- GameDev Stack Exchange：游戏开发专项问答
- 华为 / 鸿蒙开发者论坛：鸿蒙生态开发社区
- ET 社区：大佬博客 / GitHub 收集帖
