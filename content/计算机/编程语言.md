> 阶段：01-学习与基础  

## 定位说明

以 Unity 开发为出发点的编程语言入口汇总，涵盖 C++/C#/Lua/PHP/Markdown 常用学习与参考资料。深度 API 参考见 [[C-CSharp-CPP参考]]。

## 一、C++ 入门与现代特性

- 入门推荐《现代 C++ 教程》（changkun.de），覆盖 C++11/14/17/20 核心特性
- 在线参考：cppreference（中英文）、cplusplus.com 配合使用
- 在线编译测试：Coliru / Compiler Explorer / C++ Insights — 见 [[在线工具与协作]]

## 二、C# 语言专题

- **Enum / Flag 枚举**：游戏开发中常用于状态位组合，`[Flags]` 特性配合位运算使用
- **多线程与并发**：`Thread`、`ConcurrentQueue`、`Task`、`async/await` 是 Unity 客户端与服务端常用模型
- **综合参考**：MSDN C# 语言参考是最权威的官方入口，推荐先看官方再看博客

## 三、Lua

- Unity 热更新方案（XLua / ToLua）的脚本语言，理解 `string.gsub`、元表、闭包是关键

## 四、PHP

- 主要作为服务端脚本参考，php.net 函数手册是标准查阅入口

## 五、Markdown

- Quartz 笔记格式，掌握 KaTeX 数学公式语法可覆盖大多数场景

## 六、C 语言入门

- C 语言是底层基础，堆/栈、进程/线程、编码原理等 CS 基础与 C 语言高度相关
