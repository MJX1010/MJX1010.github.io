## 定位说明

Apple / Android / 华为 / Google 平台开发者文档入口，以及 C++ / Google 等主流代码风格规范。主要用于发布流程查阅和代码规范参考，与 [[Unity-Android-iOS平台问题笔记]] 互补。

## 一、Apple 平台

- Apple Developer（developer.apple.com）是 iOS/macOS 发布、证书、内购的权威入口
- launchd.plist 配置适用于 macOS daemon / LaunchAgent 场景

## 二、Android 平台

- developer.android.com 是 Android 官方文档总入口，含 API 参考和最佳实践
- Android Code Search（cs.android.com）适合查阅 AOSP 源码实现
- 注意 Android 16 KB Page Size 等版本兼容要求（详见 [[Unity-Android-iOS平台问题笔记]]）

## 三、Google / 其他

- Google Code Wiki（codewiki.google）：Google 内部开发规范和实践汇总
- Google Style Guides（google.github.io/styleguide）：C++、Java、Python、Shell 等多语言规范，业界广泛参考

## 四、华为云 / 鸿蒙

- 华为开发者联盟：AGConnect 云函数、HMS Core SDK、鸿蒙开发入口
- 华为云开发者空间：云服务 SDK 和开发文档

## 五、代码风格规范

- **C++ Core Guidelines**（isocpp.github.io）：Stroustrup 主导的 C++ 最佳实践，权威性最高
- **Google Style Guides**：多语言统一规范，团队协作场景首选参考
