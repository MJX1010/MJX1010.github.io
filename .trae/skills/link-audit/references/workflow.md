# Link Audit Workflow

## 目标

- 用脚本化方式完成外链体检、计划生成、批量修复和复检。
- 让公开区优先达到 `broken=0`、`error=0`、`auth=0`。
- 对私有区失效入口，不保留可点击坏链，改成“失效归档”文本。

## 分类规则

### 可替换

- 官方主页
- 官方文档
- 主仓库
- 稳定产品入口

### 应归档

- 登录页
- 个人页
- 内网页
- 控制台页
- 老旧帖子
- 受限下载页

### 可保留但不当主入口

- 社区帖子
- 单条 issue
- release 页面
- 搜索结果页

## 执行顺序

1. 跑体检。
2. 从报告里抽取目标文件和异常 URL。
3. 写 `link_fix_plan_*.json`。
4. 跑修复脚本。
5. 再跑体检确认结果。

## 验收标准

- 公开区异常优先清零。
- 私有区死链不再保留为 Markdown 可点击链接。
- 计划文件与报告留存在 `scripts/` 和 `private/link_audit/`，便于回放。
