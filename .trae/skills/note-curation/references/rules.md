# Note Curation Rules

## 核心原则

- 全量整理，不留“待整理”状态。
- 禁止只贴链接，必须先读内容再提炼。
- 优先合并现有专题笔记。
- 公开与私有严格分流。
- 清理重复入口、失效入口和低价值入口。

## 公开区标准

- 面向知识复用
- 可公开访问
- 正文先给结论、适用场景、边界和风险
- 原始链接只在仍有回看价值时保留

## 私有区标准

- 登录态
- 公司账号
- 内网
- 控制台
- 个人项目页
- 历史归档记录

## 收尾标准

- 批次材料已归档或删除
- 公开区不再有同批次待处理入口
- 主要异常链接已清理
- Markdown 诊断通过
